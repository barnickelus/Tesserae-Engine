Tesserae-Engine

Adaptive rendering from procedural tesserae. Live prototypes:

→

glb-sampler

GLB → surface tesserae. Form-validation tool: ghost-mesh overlay, normals debug, primitive mixing. Does the reconstruction still read as the model?

 →

tessera-avatar

Animated GLB → tesserae skinned to the skeleton. Do the tesserae stay attached through animation? Loading + animation + instancing stress test.

 →

semantic-tesserae

Soldier with tesserae sized by body region (face small → boots largest). Does semantic sizing improve readability more than just more tesserae?

 →

importance-tesserae

Perception engine, first step. Tesserae adapt by an importance map — dense + small + glyph-faced where it matters, large where it doesn't — with a continuous abstraction slider (1%→100%).

 →

tessera-materials

Primitive shape as a material language. Each material is a recipe of shape + faceplate + finish — skin, metal, cloth, hair, glass, stone — applied whole or mixed by region.

 →

tessera-volume

Solid, not a hollow shell. Flood-fills the interior into a volume of tesserae, then tests transparency-by-accumulation: thin → translucent, thick → opaque. Matter, not a skin.

 →

tessera-occupancy

Adaptive sparse-voxel tesserae. Subdivide a tessera into a cube of sub-tesserae where detail is needed; each cell's opacity = surface coverage, so empty space vanishes (no negative-space gaps).

 →

primitive-cloud

GPU-instanced benchmark, 10k–1M primitives, with an Animate Tesserae toggle. How many (animated) tesserae can this device push?
Source: barnickelus/Tesserae-Engine. Best on a desktop GPU; also runs on iPad Safari.
